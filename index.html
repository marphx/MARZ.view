MARZview — complete how-to guide

This page explains every major screen, control group, and mapping tool. Use it as your help center before launching, or reopen it from the app with the Help button.

1) Quick launch flow

  1. Start on the home page and tap Start Camera + Mic.
  2. Read through this guide, then tap Launch at the bottom.
  3. The cactus loading screen plays.
  4. MARZview opens with the live camera, the microphone, and the control dock.

Tip: if you are projecting live, use Hide UI or the small gray dot to keep the output clean while still controlling the app from your keyboard.

2) Main screens and buttons

3) Effects and visual controls

  • Primary / Secondary Effect: choose up to two visual layers and blend them together.
  • Primary On / Secondary On: turn each effect layer on or off without losing the chosen effect.
  • Normal Sharp: switches between a cleaner source render and a softer lower-bitrate render.
  • Sliders: intensity, glow, trail, texture, bitrate, color drift, edge boost, feedback, zoom warp, camera ghost, mic sensitivity, export bitrate, and FPS each change part of the visual response.

4) Projection mapping workflow

  1. Open the Map panel.
  2. Turn mapping on if needed and choose a shape or use Custom.
  3. Drag the frame, drag corner points, or add/remove custom points.
  4. Use Mask to hide everything outside the shape, or Warp to contort the visual inside the shape.
  5. Use the content controls to zoom, pan, and squish the image inside the frame. Tap Refresh Map if you ever want to force the latest contour/stretch placement to snap into view.
  6. Use Trace Subject, Tight Trace, or Box Trace to detect a dominant subject and create a more precise frame automatically.

5) Uploaded media, GIFs, and duplicated live frames

  • Upload photos, videos, and GIFs into the piano-style media slots.
  • GIFs loop automatically and are held until loaded so black placeholder frames are less likely to appear.
  • Add Source Frame duplicates the currently active live source or media source into another mapped frame.
  • Frame 1–4 buttons select which mapped frame you are editing.
  • Frame visuals lets each mapped frame use its own primary and secondary visual modes. Use this selectively for performance when running several frames at once.
  • Swap Frames rotates the assigned sources between active mapped frames while preserving each frame’s dimensions and shape.

6) Selecting, copying, pasting, and undoing mapped frames

  • While the Map panel is active, tap a mapped frame on screen to select it for editing.
  • With a mapped frame selected, press ⌘/Ctrl + C to copy that frame.
  • Press ⌘/Ctrl + V to paste it into the next available mapped-frame slot.
  • Press ⌘/Ctrl + Z to undo mapping actions, and ⌘/Ctrl + Shift + Z or ⌘/Ctrl + Y to redo them.
  • Undo / redo in mapping mode is designed for map placement, point edits, zoom/pan/squish adjustments, trace actions, frame duplication, and frame clearing.

8) Exporting and live use

  • Use Record to capture the visual output together with audio when the browser supports it.
  • Use Snapshot to save a still PNG frame.
  • When projecting, hide the UI and control the app from a keyboard for cleaner output.
  • On iPhone / iPad, browser-level system indicators may still appear depending on Safari limitations. This build uses the strongest available fullscreen and standalone web-app settings, but iOS may still keep the status area visible.
